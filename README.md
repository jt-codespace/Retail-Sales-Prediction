# Retail Sales Prediction Project

This is a simple Machine Learning project made using Python.

The project analyzes retail store data and predicts future sales using Linear Regression.

## Features
- Data Analysis
- Data Visualization
- Sales Prediction
- Machine Learning Model

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
The dataset contains:
- Advertising Spend
- Number of Customers
- Sales Data

## Output
- Graphs and charts
- Predicted future sales
- Basic business insights
